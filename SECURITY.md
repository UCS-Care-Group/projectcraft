# Security policy

Report a vulnerability privately through GitHub: open the repository's **Security** tab and choose
**Report a vulnerability** (https://github.com/UCS-Care-Group/projectcraft/security/advisories/new).
Don't open a public issue. Only the reporter and the maintainers see the report; we reply inside it.

Use invented projects in reproductions, never a real organisation's plan. A malformed project file
that crashes ProjectCraft or makes it hang counts as a vulnerability.

Supported versions: the latest release only (pre-alpha).
