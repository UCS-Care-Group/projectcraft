# 0002. The name ProjectCraft

> **Status:** accepted · **Date:** 2026-10-15 · **Deciders:** Martin Ball

## Context
The project started as PlanCraft, picked only because no Craft app used it. Before publishing, the name was checked. PlanCraft clashed: a German construction product (plancraft.de), a schedule/Gantt generator on GitHub, and taken `.com`/`.app`/`.dev` domains. ProjectCraft was the owner's preference, and the Remade directory's open request for a Microsoft Project reimplementation suggested it.

## Decision
The project is **ProjectCraft**: crates `projectcraft-*`, binaries `projectcraft` and `projectcraft-cli`, files `.projectcraft`. Nothing had been published under PlanCraft, so the old names are not read.

## Evidence (2026-10-15)
- **Trademarks:** the USPTO register has no live mark (two dead ones: PROJECTCRAFT, class 45 legal services, lapsed; PROJECT: CRAFT, craft supplies, abandoned), and none in classes 9 or 42. The owner checked the UK IPO and EUIPO (TMview) registers: clear.
- **Software in use:** "Project Craft Platform", cloud construction project-management software (Capterra), is the nearest; different product and audience, no registered mark found. A London video game of the same name is unrelated.
- **Names:** crates.io `projectcraft` free; no significant GitHub project; `projectcraft.com` parked for sale, `.dev` taken, `.io`/`.org`/`.app` unregistered when checked.

## Consequences
- "Project" echoes the Microsoft product's name, as "Word" does in WordCraft; NOTICE and README disclaim affiliation.
- Registering the mark (UK, classes 9 and 42) is open and is the owner's decision.
